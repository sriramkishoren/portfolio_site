Privacy policy

personal-agent · effective October 11, 2026

personal-agent is a private tool that its developer, Sriramkishore Naraharisetti, runs on his own computer for his own email. It is not offered to anyone else, and the only Google account it connects to is his own. This policy describes what it does with that account's data.

What it reads

  • Through the read-only Gmail scope (gmail.readonly), it reads new inbox messages: the sender, subject, date, Gmail labels such as the inbox tab or "important", and Gmail's short preview of the message.
  • For the few messages it judges important, when the preview is too short to understand, it also reads the message text, with quoted replies and signatures removed and limited to 4,000 characters.
  • It never sends, deletes, moves, labels or otherwise changes mail.

How it uses the data

  • The only use is a private summary email sent each weekday morning to the developer's own address: messages that need attention, tasks and deadlines, and suggested replies he can choose to send himself.
  • To write the summary, the data above is sent to Anthropic's Claude API. Under Anthropic's commercial terms, data sent through the API isn't used to train its models. It isn't sent to any other service.
  • It is not sold, not used for advertising, and not read by anyone other than the developer.

What it stores

  • Everything stays on the developer's own Mac, in files readable only by his user account.
  • It keeps the IDs of messages already summarized, so it doesn't summarize them twice (deleted after 90 days), short task descriptions such as "pay the water bill by Oct 15", and logs of when it ran and how much it cost.
  • When the developer runs it by hand in test mode, it saves that one summary as a file instead of emailing it.
  • It does not store full email text.
  • The Google sign-in token is kept in a file readable only by the developer. Passwords and API keys are kept in the macOS Keychain.

Google API Services User Data Policy

personal-agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from myaccount.google.com/permissions. Deleting the tool's data folder on the Mac removes everything it stored.

What Makes AI Generative?

"It's the total buzz all over the internet, all across industry, generative AI."

Understanding where generative AI fits — and how it works — is essential for making informed adoption decisions. This overview aims to demystify generative AI. We will explore what a large language model is, how transformer models serve as the foundation of modern generative AI, and trace an evolution of image generation that goes back 50 years.

The Goal: Equip you to discuss these technologies intelligently with colleagues and make better decisions about adopting generative AI solutions in your organization.

The Engine

Uses statistical probabilities, stochastic processes, and randomness to identify patterns.

Deep Learning Subdiscipline

Operates in much the same way but uses neural networks for incredible performance with large data.

Two Core Types

Fundamentally divided into Discriminative (classifying) and Generative (creating new content).

Discriminative vs. Generative

The core conceptual distinction that defines Generative AI.

Discriminative

Classify New Data

"It's Red"

Draw a line that separates data classes (red and blue). When a new point emerges, classify it based on which side of the line it falls on.

Generative

Generate New Data

Use probabilities to go backwards to the same model. Sample from the distributions to plot where X would end up, generating a new example.

Generative AI goes backwards through the same model to generate new data using probabilities.

The Inverse Problem: Forward vs. Backward

How the same architecture operates in opposite directions.

Forward Direction (Discriminative)

Input Image
Class A
Output Dist.

Propagate node through neural network to determine an output distribution of a given class.

Backward Direction (Generative)

Random Input
Generated

Take random input, go backwards through the same hidden layers, and create a generative example.

"Generative AI is simply taking these amazing deep learning models and going the opposite way through the model to do the inverse problem."
